INSTAT Explorer
===============

Start here. Shqip më poshtë.

Nothing has to be installed: this folder has everything in it, Python included.

1. Unzip the WHOLE download (right-click the zip file, "Extract All") and open the new
   folder. Do not start the program from inside the zip file.

2. Double-click Start-INSTAT-Explorer.bat (INSTAT-Explorer.exe next to it does the same).
   If Windows says it protected your PC, choose "More info" and then "Run anyway": the
   program is not signed, because certificates cost money. A computer that only accepts
   signed programs may refuse the .exe. The .bat file starts the signed python.exe, so it
   is usually accepted.

3. Your browser opens with the program. Keep the black window open while you work and
   close it to stop the program.

4. If something does not work, double-click Check-installation.bat and show the result to
   whoever looks after the computer.

You need 64-bit Windows 10 or 11. The folder can be copied to a USB stick or another
computer. Downloaded files and exports are kept in the "data" folder next to this file.
README.md has the rest.

The program is free (MIT licence, see LICENSE). It is not made by INSTAT and has no
connection to them; the data belongs to INSTAT. This folder also holds Python
(python\LICENSE.txt) and the libraries pandas, numpy and xlrd, each with its own licence.


Shqip
-----

Nuk ka asgjë për të instaluar: kjo dosje ka gjithçka brenda, edhe Python-in.

1. Shpaketo TË GJITHË zip-in (kliko me të djathtën, "Extract All") dhe hap dosjen e re.
   Mos e nis programin nga brenda skedarit zip.

2. Kliko dy herë Start-INSTAT-Explorer.bat (INSTAT-Explorer.exe pranë tij bën të njëjtën gjë).
   Nëse Windows thotë se të ka mbrojtur kompjuterin, zgjidh "More info" dhe pastaj
   "Run anyway": programi nuk është i nënshkruar, sepse certifikatat kushtojnë para.
   Një kompjuter që pranon vetëm programe të nënshkruara mund ta refuzojë .exe. Skedari
   .bat nis python.exe të nënshkruar, ndaj zakonisht pranohet.

3. Hapet shfletuesi me programin. Mbaje dritaren e zezë të hapur sa kohë punon dhe mbylle
   për ta ndaluar programin.

4. Nëse diçka nuk punon, kliko dy herë Check-installation.bat dhe ia trego rezultatin
   personit që kujdeset për kompjuterin.

Të duhet Windows 10 ose 11, 64-bit. Dosja mund të kopjohet në një USB ose në një kompjuter
tjetër. Skedarët e shkarkuar dhe eksportet ruhen në dosjen "data" pranë këtij skedari.
README.md ka pjesën tjetër.

Programi është falas (licenca MIT, shih LICENSE). Nuk është bërë nga INSTAT-i dhe nuk ka
lidhje me të; të dhënat janë të INSTAT-it. Kjo dosje përmban edhe Python-in
(python\LICENSE.txt) dhe bibliotekat pandas, numpy e xlrd, secila me licencën e vet.
