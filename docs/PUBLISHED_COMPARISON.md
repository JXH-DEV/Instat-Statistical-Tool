# INSTAT Explorer 0.10.1 against INSTAT's own published figures

Generated by `tools/check_published.py`. For each figure that an INSTAT press release states, the program's number from the Excel table of the same data. A figure *matches* when the program's number, rounded as INSTAT rounded it, is the published one.

**149 figures compared: 140 match, 1 match when INSTAT's rounded levels are used, 7 close (approximate by design), 1 differ, 0 could not be compared.**

**How to read it.** *match*: the program's number, rounded as INSTAT rounded it, is the published one. *match (rounded levels)*: INSTAT worked a change out from levels it had already rounded (8.5 to 8.3 is published as -0.2, the unrounded levels give -0.26). *close*: the figure is one the program only approximates (the contributions of groups to inflation use the published weights and ignore chain-linking), accepted within 0.02 percentage points; the largest deviation is in the table. *differ*: a real difference, to be explained.

**What it shows, and what it does not.** It shows that for these figures, which INSTAT chose to state in the press releases of ten data sets, the program reads or works out the same numbers from the Excel tables. It does not show that every cell of every table is read right: INSTAT publishes about 640 files and these are the headline figures of the latest releases. The tables on the site can be revised after a release, and a release can contain a typing slip, so a difference may be on either side.
